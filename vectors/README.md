# vectors

`jwks.json` and `tokens.json` are the token vectors of `verification/rules.md`
(see the repository README, "Run the token vectors").

## cauthy-key.json

Generated by `cd conformance && go run ./cmd/gen-key-vectors ../vectors` from
`key/cauthy-key.md`'s reference (`conformance/cauthykey`). `valid[]`: a key, what
it parses to, every derived key (hex), the public JWK, the `kid` and one exact
assertion (Ed25519 is deterministic). `invalid[]`: a key and the reason it is
refused. SDKs vendor the file and pin its sha256. Every secret is a test value.

`node --test vectors/cauthy-key.test.mjs` recomputes every valid vector with
WebCrypto only, as a browser would.
